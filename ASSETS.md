# ASSETS — licence ledger

## Summary

**Egg Heist: Wildlands ships with zero third-party asset files.**

Every texture, mesh, sky, sound and piece of music in this game is generated
at runtime by code in this repository. There are no `.hdr`, `.glb`, `.png`,
`.jpg`, `.mp3` or `.wav` files in the build output, and the game makes no
network request to any host other than the one serving it.

That is a deliberate decision (see `DECISIONS.md`, M0) and it is verified by
an automated test: `tests/e2e/network.spec.ts` intercepts every request the
page makes and fails the build if any of them leaves the origin.

## What is generated, and where

| Asset                                                  | Generated by                                 | Technique                                                                                                         |
| ------------------------------------------------------ | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Sky and environment lighting                           | `src/render/sky/`                            | Preetham-style physical sky evaluated into a cubemap, then PMREM-filtered into an environment map, once per biome |
| Terrain heightfield                                    | `src/render/world/terrain.ts`                | Layered simplex-style value noise, ridged for the dunes                                                           |
| Terrain albedo / normal / roughness                    | `src/render/materials/proceduralTextures.ts` | Canvas2D noise composited to `DataTexture`, triplanar-blended by slope and altitude in the shader                 |
| Foliage (birch, pine, fern, grass, reed, palm, cactus) | `src/render/world/foliage.ts`                | Parametric geometry, GPU-instanced, alpha-hashed, vertex wind                                                     |
| Rocks and ruins                                        | `src/render/world/props.ts`                  | Noise-displaced icospheres and boolean-free box assemblies, seeded per biome                                      |
| Eggs                                                   | `src/render/entities/eggMesh.ts`             | Parametric superellipsoid, shell pattern from a noise field                                                       |
| Creatures                                              | `src/render/entities/creatureMesh.ts`        | Parametric body from the knobs in `src/data/creatures.ts`                                                         |
| Player and guardians                                   | `src/render/entities/`                       | Same parametric builder, procedurally animated                                                                    |
| Water                                                  | `src/render/materials/waterMaterial.ts`      | Custom shader: depth ramp, screen-space reflection, animated normals, intersection foam                           |
| All sound effects                                      | `src/systems/audio/synth.ts`                 | WebAudio oscillators, noise buffers and filters                                                                   |
| Music                                                  | `src/systems/audio/music.ts`                 | WebAudio, procedurally sequenced folk-orchestral layers                                                           |
| Fonts                                                  | —                                            | System font stack only. No webfont is downloaded.                                                                 |

## If you add an asset later

Add a row here first, with the source URL, the licence, and the date you
verified the URL resolves. An asset with no ledger row is a build failure
waiting to happen.
